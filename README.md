# Task_8

## 📊 Overview
This project is a simple interactive sales dashboard created in **Power BI** using the provided `Superstore_Sales.csv` dataset. The dashboard shows sales performance by **Product Category**, **Region**, and **Month-Year**.

## ✅ Features
- **Line Chart**: Sales trend over Month-Year
- **Bar Chart**: Sales by Region
- **Donut Chart**: Sales by Category
- **Slicer**
